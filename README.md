# Object-oriented programming
Объектно-ориентированное программирование
## О проекте
Проект сделан в рамках обучения работы с классами и их созданию с использованием Python-языка
## По установке:
  * Для PyCharm:
    1. клонировать репозиторий, введя в терминале git clone 
    2. установить зависимости через активированное виртуальное окружение: pip install -r requirements.txt(не добавлено в проект)
  * Для GitHub:
    1. на странице проекта на кнопке <> Code открыть выпадающий список
    2. выбрать download zip или клонировать через ссылку https или ssh
## По применению проекта:
1. открыть модуль main через pycharm
2. сделать пробег у current file/комбинацией shift + f10/командой python src\main в терминале
## Дополнительно
В функционал проекта входит:
1. базовый класс содержит общие методы для классов и подклассов(кроме класса категория)
2. класс-миксин для ведения дебаг-отчета
3. класс продукт - основной набор функций
4. класс смартфон - подкласс с расширением основного набора функций
5. класс газонная трава - подкласс с расширением основного набора функций
6. класс категория - дополняет основную функциональность и ведет учет
- в src находится модуль для работы с классами
- все main, будучи пусковыми модулями, запускают код, на основе которого создается и дорабатывается src директория (подстраивает под себя выполнение домашнего задания)
